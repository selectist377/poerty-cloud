# 诗云 Poetry Cloud

> 三节十二行 · 八轮筛查 · 五维盲测 · 可复核审计

诗云是一份面向**现代汉语**的固定形式写作协议与配套的自动化验收流水线。它把“写一首十二行诗”拆成可执行的规则、可复核的检查与可追溯的证据，再用五个审美倾向不同的评审配置做背靠背盲测，最后产出可离线阅读的静态页面。

在线页面：<https://selectist377.github.io/poerty-cloud/>

## 项目简介

固定形式的诗歌最难的地方不在“凑够行数”，而在于形式与语义同时成立：A 类行必须是一个 14–18 字的完整长句，B 类行必须由两个各 8–10 字的短句以一个空格分隔；三节之间要有压力变化，同节之内同一实义词项不得重复，虚词又不得按配额删改。规则越密，越容易被字面满足——所以协议把“硬性门槛”和“质量诊断”分成两条轨道：硬性门槛一票否决，评分只作分层与复查定位。

v3.9 的主要变化是把 `N≥90` 从最终成稿的一票否决条件降级为**辅助诊断指标**，取消虚词的机械配额，并把“规格博弈三问”写进交付前的必答项。本仓库据此实现了从诗稿、评分、门槛核验到报告与网页的完整链路。

## 核心特性

- **十二行生成式诗歌写作协议（v3.9）**：三节十二行，A/B 行式，逐字计数，任何改动都使旧计数失效。
- **八轮筛查 + 反向审计 + 形式核验**：词项、语法、结构、节奏、美学、可进入性、流程合规、压力测试。
- **五维量化评分体系（N 分制）**：IR / MH / SD / SI / II，每维去掉最高最低取中间三个均值。
- **多配置盲测评审**：R1–R5 五个评审配置独立打分，按固定权重与固定抖动复现。
- **全自动化终稿生成流水线**：G1–G10 核验、去极值聚合、报告、诗集、证书、网页一次生成。
- **零外部依赖**：纯静态页面，无 CDN、无字体请求，双击即可离线打开。

## 快速开始

```bash
# 1. 校验 100 首诗的形式（G1–G3、G4、G6、G7、G8 的可计算部分）
python3 tools/validate_poems.py data/poems_source.json --strict

# 2. 复现五个评审配置的评分
python3 tools/score_poems.py

# 3. 计算 G1–G10 与去极值 N 分，输出报告、诗集、证书、门槛矩阵
python3 scripts/generate_final.py

# 4. 重新排版协议（含校订）
python3 tools/format_protocol.py

# 5. 重新生成静态页面
python3 tools/build_site.py
```

网页部分无需构建工具：直接用浏览器打开 `index.html` 即可，或访问 GitHub Pages。

## 评分体系说明

| 维度 | 名称 | 评分要点 |
| --- | --- | --- |
| IR | 意象共鸣度 | 意象选取的精准度、画面感、情感唤起能力 |
| MH | 音韵和谐度 | 节奏感、停顿合理性、诵读流畅度 |
| SD | 语义深度 | 思想内涵、多层次解读空间、避免陈词滥调 |
| SI | 结构完整性 | 三节推进逻辑、起承转合、首尾呼应 |
| II | 创新指数 | 陌生化表达、反模板程度、语言实验性 |

- 每个维度由 5 个评审配置各给 0–20 分（精确到 0.5 分）；
- 去掉最高分与最低分，取中间 3 个的算术平均，保留一位小数；
- 五个维度的均值之和为总分 **N**（满分 100）；
- 准入条件：**G1–G10 全部通过** 且 **五维单项均不低于 15 分**；
- `N≥90` 是辅助诊断标签，不作为准入的一票否决条件，也不能抵消硬性错误。
